Remote MCP server · free · no API key

Let your AI assistant check Indian KYC details

Connect Claude, Cursor or any MCP client to one URL. It can then look up IFSC and PIN codes live, check GSTINs and PANs, and run a full vendor onboarding check in one call, instead of guessing.

Connect

One URL, any assistant

Nothing to install or sign up for. Every tool only looks things up, so the server never sees or stores anything else.

Run this once in your terminal:

claude mcp add --transport http india-kyc {{MCP_URL}}
  1. Open Settings → Connectors in Claude on the web or desktop.
  2. Choose Add custom connector.
  3. Paste the URL: {{MCP_URL}}

Add this to .cursor/mcp.json:

{ "mcpServers": { "india-kyc": { "url": "{{MCP_URL}}" } } }

Or run it on your own machine over stdio (needs Python 3.10+):

pip install "git+{{REPO}}"
claude mcp add india-kyc -- india-kyc-mcp
